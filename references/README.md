# Official reference registry research seed

The source catalog contains links and titles from Acquisition.gov retrieved on November 15, 2026. It does **not** copy authoritative clause text or codify any applicability decisions.

`npm run references:validate` checks unique identifiers, source structure, and a restricted source host. It does not check whether links remain available or whether the source is currently legally operative.

## Required next controls

1. Verify the exact applicable regulatory and contractual versions, including deviations and award/modification dates.
2. Capture official clause text, prescriptions, paragraph-specific flow-down instructions, and the exact source section in a versioned, traceable corpus.
3. Obtain an independent subject-matter review of every intended decision rule. Maintain separate review sign-off from software authorship.
4. Validate commercial versus noncommercial subcontracts, scope, location, dollar thresholds, prime-specific clauses, and agency supplements.
5. Test in an approved private environment using sanitized or authorized examples. Never place Chugach CUI or proprietary statements of work in this public repository.

No source in this registry is approved for automatic inclusion or exclusion. The app's fictional rules remain completely separate.
